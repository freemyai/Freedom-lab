# Freedom Lab

A local-first experimental personal AI system.

## Stack

- Hermes Agent
- Hindsight
- Qwen3.8
- Ollama
- Docker

## Principles

- memory belongs to owner
- model is replaceable
- permissions belong to owner
- private by default
- local first
- freedom in cognition does not imply unlimited action authority

## Start

./scripts/doctor.sh
hermes

## Stop

Exit Hermes.
Ollama and local services may remain running.

## Backup

./scripts/backup.sh
